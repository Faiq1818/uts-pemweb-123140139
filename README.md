## Cara Menjalankan
1. Copy repository ini
```
git clone https://github.com/Faiq1818/uts-pemweb-123140139.git
```
2. Masuk ke root folder projectnya
3. Install dependensi
```
npm install
```
4. Jalankan localhostnya
```
npm run dev
```
5. Cek localhost http://localhost:5173/
